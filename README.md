# Apex Advisory - Wealth Architecture Landing Page

A sophisticated, dark-themed landing page for a high-net-worth financial consulting firm.

## Project Overview

This project is a premium landing page designed for Apex Advisory, a high-net-worth financial consulting firm. The design emphasizes exclusivity, trust, and discretion through a sophisticated dark theme with luxury gold and burgundy accents. The page showcases the firm's services, team expertise, and client journey in an elegant, professional manner.

## Features

- **Dark Theme Design**: Deep charcoal background with gold and burgundy accents
- **Responsive Layout**: Built with Bootstrap 5 for mobile-first design
- **Smooth Animations**: Enhanced with custom JavaScript for hover effects and smooth scrolling
- **Professional Typography**: Playfair Display for headings, Inter for body text
- **Interactive Elements**: Team member modals, animated counters, and parallax effects
- **Luxury Aesthetics**: Generous whitespace and sophisticated visual hierarchy
- **Mobile Optimized**: Fully responsive design for all device sizes
- **Performance Focused**: Optimized images and efficient code structure

## Technologies Used

- **HTML5**: Semantic markup and modern web standards
- **CSS3**: Custom Properties, Flexbox, Grid, and advanced animations
- **Bootstrap 5**: Responsive grid system and utility classes
- **JavaScript (ES6+)**: Modern JavaScript with smooth scrolling and interactions
- **Font Awesome**: Professional icon library
- **Google Fonts**: Playfair Display and Inter typography
- **Unsplash**: High-quality stock photography

## Setup Instructions

1. **Download/Clone**: Download or clone the project files to your local machine
2. **Open in Browser**: Simply open `index.html` in any modern web browser
3. **No Build Process**: The project runs directly without any compilation or build steps
4. **Local Development**: Use a local server (optional) for best development experience
5. **Customization**: Modify colors, content, and styling in the respective files
